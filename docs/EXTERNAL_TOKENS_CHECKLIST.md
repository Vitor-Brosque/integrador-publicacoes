# External Tokens Checklist

## Instagram
- Campos necessarios: `account_name`, `status`, `external_account_id`, `access_token`, `page_id` quando aplicavel, `token_expires_at` quando houver expiracao, `metadata` se precisar registrar informacoes extras.
- Onde preencher no app: `/integrations/instagram/`.
- Primeiro teste recomendado: `single_image`.

- Nao registrar segredo nem valor sensivel aqui.
