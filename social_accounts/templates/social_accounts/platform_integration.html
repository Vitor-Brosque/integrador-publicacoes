Como configurar

  • Instagram: external_account_id = Instagram Business Account ID.
  • Instagram: access_token = token Meta com permissão para publicar.
  • Facebook: external_account_id = Facebook Page ID.
  • Facebook: access_token = Page Access Token.
  • Google Business: external_account_id = accounts/{accountId}/locations/{locationId}.
  • Google Business: access_token = OAuth com permissão para gerenciar a ficha.
  • YouTube: external_account_id = channel_id.
  • YouTube: access_token = OAuth com permissão de upload.
  • TikTok: external_account_id = open_id/creator id.
  • TikTok: access_token = TikTok user access token.
